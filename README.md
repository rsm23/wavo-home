# Wavo Homepage

Interactive Next.js homepage for Wavo, including financing simulations, eligibility guidance, responsive layouts, dark mode, and Three.js product visuals.

## Local development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```

The production build is a static export generated in `out/`.

## Deployment

Pushes to `main` are built and deployed automatically with GitHub Actions. The published site is available at [https://rsm23.github.io/wavo-home/](https://rsm23.github.io/wavo-home/).
